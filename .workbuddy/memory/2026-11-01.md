# 2026-11-01

## 自制图上线：提示词站接入覆盖层（第 2 层打通）

用户要求「把素材管理器里自己加的图送进提示词静态站」。之前我建议不做（授权混、仓库膨胀、own 集合是正确位置），用户明确要做，于是设计成**覆盖层**而不是混进上游数据。

**三个不能动的边界（先摸清再动手）**
1. `data/prompts_<key>.json` 是 `import_youmind.py` 的产物，重抓整份重写 → 自制图不能写进这里。
2. `load_manifest()` 用 `r["file"]` 的 `img/<key>/` 推分片键 → 自制图放 `img/user/` 会变成第 3 个「模型」分片。
3. `fetch.py` 只认 `manifest.json` 里的文件 → 自制图放进 `img/` 会让「图片比清单多」成为噪声。

**最终设计**
- 图片放 `sites/prompts/userimg/`（与 `img/` 平级），缩略图 `userimg/thumbs/*.webp`；**两者入库**（自己的图无法从上游重下），已验证不被 `.gitignore` 的 `sites/*/img/` 匹配。
- 归属写 `data/user_assets.json`（`{version, items: {originId: [ {name,file,thumb,w,h,ar,own} ]}}`），入库。
- 分片 files 项扩到 7 元：`[名, 宽, 高, 比例, 真实路径, 缩略图路径, 1]`；前 4 元与原来完全一致，`normalizeShard` 用 `f[4] || "img/"+key+"/"+f[0]` 兼容。
- 灯箱：自制图缩略图虚线框（`.lbfiles img.own`），meta 行「自制」徽标由 `syncOwnChip()` 跟随当前张切换（同一条素材里上游图与自制图混排）。

**改动**
- 新增 `sites/prompts/sync_user_assets.py`：读 `gallery.db` 的 `role='user'` → 复制原图/缩略图到 `userimg/` → 写覆盖层。`--dry-run`/`--prune`/`--db`。幂等（大小一致跳过）。
- `scripts/build_gallery.py`：`load_user_assets()`、`group_user_assets()`（含 orphan 警告：上游换批后提示词整条消失不能静默丢）、`shard_payload(rows, extra)`、`check()` 校用户图、统计口径 `n`/`total`/`__COUNT_HINT__` 全含自制图。
- `config.py`：`USER_ASSETS`/`USER_IMG_DIR`/`USER_THUMB_DIR` + `own`/`ownTip` 双语文案。
- `tests/run.py`：新增 `UserAssets` 4 项（结构、路径必须在 userimg/、图片存在、userimg 必须入库）。
- 文档：NOTICE.md 加「例外：站主自制图」（明确不在 CC BY 4.0）、README 加「给提示词加自己的成图」、AGENTS 规则 15、`userimg/README.md`。

**实测（真实 41k 数据 + 浏览器）**
- attach 两张到 `prompts:gpt2-13440` → `sync_user_assets.py` → build：`gallery.js` total 41,261→41,263，分片该条 files=3（第 5/6/7 元带 userimg 路径）。
- 8099 上卡片角标 `1 2 3`，点第 3 张换图、不误触灯箱；灯箱缩略图第 3 张虚线框。
- 再挂一张到 `prompts:gpt2-13983`（桃太郎，prompt 短），灯箱里 `→` 切到第 3 张：**meta 行出现「自制」徽标**，页脚「共 41264 张图」。核对无误。
- 测完清理：删 3 条 `role=user` 链接 + 3 张 library 图 + `userimg/`，覆盖层回到 `items: {}`，重建后 total 恢复 41,261、两条素材 files 回到 1 / 2。`build_gallery.py --check` 41,261/41,261。
- 测试：`tests/run.py` 34 项（30+4）、`tests/test_manager.py` 85 项全绿。

**环境坑**
- `tools/serve.py` 只给 HTML 加 `no-cache`，`data/gallery_*.js` 会被浏览器缓存 → 改数据后必须换端口（8099→8100→8101）才看得到新分片，否则会误判成「构建没生效」。
- WorkBuddy 内置浏览器在标签多了以后会 `CDP Input.dispatchMouseEvent timed out` / 截图超 10 MiB；关掉异常标签或换 Chrome 扩展浏览器即可。扩展浏览器的 `cua_click` 坐标与内置浏览器不同（会点偏），优先 `dom_cua_click`。
